# LocalForge Offline-First Guarantee & Network Policy

**Version:** LocalForge v0.2.0 Autonomous Engineering Operating System  
**Classification:** Operational Security & Offline Capability  
**Date:** September 2026  

---

## 1. The Offline-First Guarantee

LocalForge is built from the ground up to operate with **zero internet connectivity**:
- **No Mandatory Cloud Account:** No sign-up, telemetry tokens, or external API keys are required.
- **Local Model Execution:** All LLM inference runs locally via Ollama (`http://127.0.0.1:11434`), LM Studio (`http://127.0.0.1:1234/v1`), llama.cpp, or vLLM.
- **Local Context & Indexing:** Workspace files and code symbols are indexed incrementally on disk without external vector databases.
- **Local Execution:** All file reads, diff computations, atomic edits, and terminal test executions run natively on the host machine.

## 3. Strict Network Isolation Rules

1. **Zero External Telemetry:** LocalForge includes no third-party analytics (Google Analytics, Sentry, Mixpanel, Datadog) in runtime dependencies.
2. **Loopback Traffic Only:** In standard offline mode, all HTTP requests generated by LocalForge target loopback addresses (`127.0.0.1`, `localhost`).
3. **Graceful Network Degradation:** If an agent attempts to invoke a web-reliant tool while offline, the runtime returns a typed `NetworkUnavailableError` rather than crashing.
