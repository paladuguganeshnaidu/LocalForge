# LOMVREN 0.2.10

The expandable run trace now reports the real terminal working directory, process ID, lifecycle status, exit code (only when supplied), stdout, and stderr. A failed launch without an exit code is no longer shown as exit code 0.

This release includes the approval-first behavior and detailed activity UI from 0.2.9/0.2.8. It remains an incremental build toward the full coding-agent goal.
