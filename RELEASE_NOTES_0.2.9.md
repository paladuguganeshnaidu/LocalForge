# LOMVREN 0.2.9

This update makes user approval the default for edits and command execution on new installs. Read-only workspace inspection remains automatic, catastrophic system operations remain blocked, and the Settings drawer keeps the selectable safe auto-run and ask-once modes.

It includes the expandable model/tool activity trace introduced in 0.2.8: visible model narration, exact tool input, bounded output, command results, and errors, with credential-like values redacted. Hidden chain-of-thought is not displayed.

The VSIX is a local release candidate. Full competitor parity and real remote-GPU host validation remain part of the ongoing goal.
